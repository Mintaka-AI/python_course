Module 4: Engineering Calculations as Tools

This module turns formulas into small, documented, validated, and tested tools. It then combines them into a command-line calculator that keeps calculation logic separate from user interaction.

Lessons

  1. Reliable calculation functions and units
  2. Mini-project: engineering calculator
The examples use Python 3.14 standard-library features. The unit-aware extension additionally requires Pint.
