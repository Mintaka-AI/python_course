Mini-project: Engineering Calculator

Learning goals

  • Separate interface, validation, calculation, and reporting.
  • Design an auditable result record.
  • Test the calculation layer independently.

1. Define scope before code

This project calculates axial stress only. Inputs are non-negative force in N and positive cross-sectional area in m². Output is stress in Pa and MPa. It does not select materials, safety factors, or approve a component.

2. Separate the program layers

calculator/
├── calculations.py  # validated formulas
├── app.py           # input, choice, and output
├── report.py        # JSON report construction
└── test_calculations.py

A layer has one kind of responsibility. The calculation layer does not call input(); therefore tests and future agent tools can call it directly.

3. Build a result record

from datetime import datetime, timezone
result = {
    "calculation": "axial_stress",
    "inputs": {"force_n": force_n, "area_m2": area_m2},
    "formula": "stress_pa = force_n / area_m2",
    "assumptions": ["uniform axial force", "positive area"],
    "result": {"stress_mpa": round(stress_pa / 1_000_000, 3)},
    "created_at": datetime.now(timezone.utc).isoformat(),
}

The report preserves original inputs, formula, assumptions, unit-bearing result name, and UTC timestamp. This is more auditable than saving only one number.

4. Save JSON safely

import json
from pathlib import Path
output_path = Path(__file__).parent / "calculation_report.json"
output_path.write_text(json.dumps(result, indent=2), encoding="utf-8")

json.dumps creates readable text. Path.write_text writes it with explicit UTF-8 encoding.

5. Test before integrating

Test known normal results, zero area, negative force, and unit conversions. Then run the command-line workflow with representative data. A test failure must stop release until its cause is understood.

6. Completion checklist

  • Clear run command and dependency instructions.
  • Validated inputs with useful errors.
  • Units visible in names and output.
  • Formula tests and boundary tests.
  • Report includes assumptions and limitations.
  • No claim that the software replaces engineering review.

Project task

Implement the project in examples/. Add one additional calculation—pressure, density, or moment—without mixing its formula into the interface layer.
