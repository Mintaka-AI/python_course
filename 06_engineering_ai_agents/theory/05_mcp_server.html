Build and Connect an MCP Server

Learning goals

  • Distinguish an MCP host, client, and server.
  • Expose a tool, resource, and prompt with the Python SDK.
  • Choose stdio or Streamable HTTP safely.

1. What is MCP?

Model Context Protocol is a standard way for an AI application to discover and use external capabilities. The host is the application used by the learner. An MCP client lives inside the host and connects to one server. The server exposes capabilities; it does not normally talk directly to the model.

2. Three server primitives

PrimitiveUsually selected byPurpose
ToolModelExecute an operation
ResourceApplicationLoad data into context
PromptUserUse a reusable message template

A calculation belongs in a tool. A read-only limitations document fits a resource. A reusable “explain this result” instruction fits a prompt.

3. Create a Python server

from mcp.server import MCPServer
from engineering_tools import calculate_stress

mcp = MCPServer("engineering-tools")

@mcp.tool()
def axial_stress(force_n: float, area_m2: float) -> dict:
    """Calculate axial stress from N and m^2."""
    return calculate_stress(force_n, area_m2)

if __name__ == "__main__":
    mcp.run()

The SDK derives the tool name, description, and input schema from the function, docstring, and type hints. Import MCPServer from mcp.server. The main guard prevents a server from starting when tests or tools import the file.

4. Run and inspect it

mcp dev examples/mcp_engineering_server.py

Run this command in the activated MSYS2 UCRT64 virtual environment. The MCP Inspector displays registered primitives and generates a form from type hints. For the local stdio transport, a host starts the server as a subprocess and communicates through standard input/output; avoid ordinary output that can corrupt that protocol stream, and use logging.

5. Transports

  • stdio is the default for local servers.
  • streamable-http is intended for deployed servers.
  • SSE is a superseded legacy transport and should not be chosen for a new server.

6. Use a remote MCP server from OpenAI

response = client.responses.create(
    model="gpt-5.6",
    tools=[{
        "type": "mcp",
        "server_label": "engineering",
        "server_url": "https://example.com/mcp",
        "allowed_tools": ["axial_stress"],
        "require_approval": "always",
    }],
    input="Calculate the stress from the supplied values.",
)

The Responses API can call a remote MCP server through its URL. Prefer a narrow allowed_tools list and require approval for sensitive actions. A local stdio server is not automatically a public remote URL.

Treat third-party MCP servers as external services. Review their data handling, tool behavior, authentication, and approval policy before sending data.

Try it yourself
