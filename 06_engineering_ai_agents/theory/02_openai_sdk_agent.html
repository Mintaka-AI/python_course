Build an Agent with the OpenAI SDK

Learning goals

  • Understand function calling in the Responses API.
  • Implement a bounded model–tool loop.
  • Keep generated arguments away from arbitrary Python execution.

1. What makes this an agent?

A normal model request produces an answer. A tool-enabled request can instead produce a function_call. Your Python program—not the model—reads that request, validates it, executes an allowlisted function, and returns a function_call_output. The model can then explain the verified output.

The model proposes a call. Your application remains responsible for authorization, validation, execution, limits, and logging.

2. Describe the tool

TOOLS = [{
    "type": "function",
    "name": "calculate_stress",
    "description": "Calculate axial stress from force in N and area in m^2.",
    "parameters": {
        "type": "object",
        "properties": {
            "force_n": {"type": "number", "minimum": 0},
            "area_m2": {"type": "number", "exclusiveMinimum": 0}
        },
        "required": ["force_n", "area_m2"],
        "additionalProperties": False
    },
    "strict": True
}]

The schema communicates the function purpose and argument contract. Strict mode improves schema adherence, but application-side validation is still required.

3. Run the loop

response = client.responses.create(model=MODEL, tools=TOOLS, input=conversation)
conversation += response.output

for call in response.output:
    if call.type == "function_call":
        result_json = execute_tool(call.name, call.arguments)
        conversation.append({
            "type": "function_call_output",
            "call_id": call.call_id,
            "output": result_json,
        })

Preserve model output as conversation state. Match every result with call_id, then call the API again so the model can read the result.

4. Stop safely

Use a maximum number of rounds, timeouts, an allowlist, argument checks, output-size limits, and missing-input handling. Never pass model text to eval(), exec(), a shell, or unrestricted file operations.

5. Engineering example

For 120,000 N and 0.0008 m², the Python function computes stress = force / area, converts Pa to MPa, and returns 150 MPa. The model explains the verified result.

Try it yourself

Run examples/openai_tool_agent.py. Remove the area and confirm that the assistant asks for it. Then add an allowlisted electrical-power tool.
