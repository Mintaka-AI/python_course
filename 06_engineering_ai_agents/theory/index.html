Module 6: Engineering AI Agents

An engineering AI agent combines a language model with declared tools and a controlled workflow. Build the same idea at several levels: plain Python, the OpenAI Responses API, LangChain, LangGraph, and MCP.

Learning path

  1. Agent foundations: tools, schemas, validation, and logs
  2. Build an agent with the OpenAI SDK
  3. Build a high-level agent with LangChain
  4. Control state and workflow with LangGraph
  5. Build and connect an MCP server
  6. Final project: verifiable engineering agent

Which layer should I use?

LayerUse it when
OpenAI SDKYou want direct control and few dependencies.
LangChainYou want a ready-made agent loop and integrations.
LangGraphYou need explicit state, branching, persistence, or human review.
MCPYou want tools and context reusable by different AI hosts.
These are educational systems. Do not let them control equipment or approve safety-critical engineering work.
