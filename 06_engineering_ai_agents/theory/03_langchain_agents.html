Build an Agent with LangChain

Learning goals

  • Explain what LangChain adds above a provider SDK.
  • Create an agent from a model, tools, and a system prompt.
  • Choose between direct SDK code and a framework.

1. What is LangChain?

LangChain is an application framework for programs that use language models. Its agent abstraction supplies a standard tool-calling loop, message format, middleware extension points, and integrations. Current LangChain agents are built on LangGraph, but beginners can use create_agent() without constructing a graph.

2. A Python function becomes a tool

from langchain.agents import create_agent
from engineering_tools import calculate_stress

agent = create_agent(
    model="openai:gpt-5.6",
    tools=[calculate_stress],
    system_prompt="Use tools for calculations. Never guess units.",
)
result = agent.invoke({"messages": [{
    "role": "user", "content": "Find stress for 120000 N and 0.0008 m^2."
}]})
print(result["messages"][-1].content)

LangChain reads the function name, type hints, and docstring to describe the tool. The function still validates ranges and calculates the result.

3. The call sequence

  1. create_agent() assembles the model, tools, and instructions.
  2. invoke() starts a run with message state.
  3. The model answers, requests missing data, or requests a tool.
  4. LangChain executes a registered tool and returns its output.
  5. The final answer is in the last message.

4. When should you use it?

Use direct OpenAI SDK code when a small loop is clearer and provider-specific control matters. Use LangChain for a standard agent interface, middleware, model portability, or integrations. A framework does not replace tests, authorization, observability, budgets, or domain review.

Every tool expands the authority of the agent. Expose only the minimum safe set.
