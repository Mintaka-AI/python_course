Final Project: Verifiable Engineering Agent

Project outcome

Build an agent for one narrow domain such as axial stress, electrical power, thermal energy, or laboratory-data summaries. Natural language may identify intent, but only verified Python tools calculate authoritative numbers.

1. Choose an architecture

  • Use the OpenAI SDK for a small, explicit function-calling loop.
  • Use LangChain for a standard high-level agent and integrations.
  • Use LangGraph for required branching, review, persistence, or recovery.
  • Add MCP when tools must be shared with other compatible hosts.

2. Required project structure

final_agent/
├── app.py          # conversation and orchestration
├── tools.py        # deterministic calculations
├── schemas.py      # validated inputs and outputs
├── report.py       # auditable report
├── tests/          # formula and workflow tests
└── README.md       # setup, scope, examples, limitations

3. Required behavior

  1. Recognize only declared intents.
  2. Ask for every missing number and unit.
  3. Normalize units explicitly.
  4. Validate types, ranges, and combinations.
  5. Call only the intended allowlisted tool.
  6. Show formula, inputs, assumptions, units, and limitations.
  7. Log actions without credentials or unnecessary personal data.
  8. Refuse unsupported or unsafe work.

4. Verification plan

Test formulas against independently derived values, invalid boundaries, and unit conversions. Test missing input, unsupported intent, tool failure, tool-round limits, and successful reporting. If an LLM is unavailable, deterministic unit and workflow tests must still run.

5. Completion rubric

AreaRequired evidence
CorrectnessKnown values and passing tests
ValidationBad and incomplete input rejected
TransparencyFormula, units, assumptions, limitations
SecurityAllowlisted tools, approvals, no eval
ReproducibilityDependencies and run instructions
The project must not control equipment, approve a design, or make autonomous safety-critical decisions.

Build the project

Start with engineering_agent.py. Choose one orchestration layer, add two calculation tools, missing-data and refusal paths, a JSON report, and automated tests. Explain why you chose that layer.
