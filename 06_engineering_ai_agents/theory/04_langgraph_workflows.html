Control Agent Workflows with LangGraph

Learning goals

  • Define state, nodes, edges, and conditional routing.
  • Recognize when a graph is more suitable than a simple agent loop.
  • Separate probabilistic model decisions from deterministic checks.

1. What is LangGraph?

LangGraph is a lower-level orchestration framework for long-running, stateful agents and workflows. A graph makes the control flow visible. It is useful when a task must branch, pause for review, recover, persist state, or repeat selected steps.

2. Four core ideas

TermMeaningEngineering example
StateData shared across the runForce, area, status, result
NodeA function that performs one stepValidate inputs
EdgeA permitted transitionValidate → calculate
Conditional edgeA transition selected from stateValid → calculate; invalid → stop

3. Build a deterministic workflow

builder = StateGraph(EngineeringState)
builder.add_node("validate", validate_inputs)
builder.add_node("calculate", calculate)
builder.add_node("report", create_report)

builder.add_edge(START, "validate")
builder.add_conditional_edges("validate", route_after_validation)
builder.add_edge("calculate", "report")
builder.add_edge("report", END)
workflow = builder.compile()

compile() checks and prepares the graph. invoke(initial_state) runs it. Each node returns only state updates, which makes the result of every step inspectable.

4. Agent loop with model and tools

A common LangGraph agent has an LLM node and a tool node. The LLM node receives messages and may create tool calls. A conditional edge routes to ToolNode when calls exist, otherwise to END. The tool node executes calls and routes back to the model. Keep deterministic validation nodes before actions with side effects.

5. LangChain or LangGraph?

Start with LangChain create_agent() for a standard model–tool loop. Move to LangGraph when you need customized routing, persistence, retries, human approval, or separate verification stages. LangChain agents already use LangGraph underneath, so the layers complement each other.
