Install the OpenAI SDK and Make a First Response

Learning goals

  • Install the official OpenAI Python SDK.
  • store the API key outside source code.
  • Send a request with the Responses API.
  • Read response.output_text.

1. Install the SDK

Activate the course virtual environment in MSYS2 UCRT64, then install the package:

source .venv/Scripts/activate
python -m pip install openai
python -m pip show openai

python -m pip installs into the Python interpreter currently selected by the virtual environment. The import name is openai.

2. Create and protect an API key

Create a key in the OpenAI API dashboard. In the current MSYS2 UCRT64 terminal, expose it as an environment variable:

export OPENAI_API_KEY="replace_with_your_key"

The SDK reads OPENAI_API_KEY automatically when OpenAI() is created. This terminal command affects the current shell session. Do not put the real key into a Python file or course material.

Never commit an API key to Git. If a key is exposed, revoke it in the OpenAI dashboard and create a new one.

3. Choose the model through configuration

import os
model_name = os.getenv("OPENAI_MODEL", "gpt-5.6")

The default matches the current official quickstart at the time this lesson was written. Keeping the model name in OPENAI_MODEL lets the learner change it without editing program logic. Model availability depends on the OpenAI project.

4. Send the first request

import os
from openai import OpenAI

client = OpenAI()
response = client.responses.create(
    model=os.getenv("OPENAI_MODEL", "gpt-5.6"),
    input="Explain in two sentences why engineering calculations need units.",
)
print(response.output_text)

5. Line-by-line explanation

  1. import os gives access to environment variables.
  2. from openai import OpenAI imports the SDK client class.
  3. OpenAI() creates a client and reads the API key from the environment.
  4. client.responses.create(...) sends a Responses API request.
  5. model selects the configured model.
  6. input supplies the user request.
  7. response.output_text returns the combined generated text for simple text responses.

6. Expected result

The exact wording can vary. A valid result should contain two sentences explaining that units define the physical meaning of values and help prevent incompatible calculations.

7. Common mistakes

  • ModuleNotFoundError: install openai.venv.
  • Authentication error: confirm OPENAI_API_KEY is present and valid.
  • Model access error: set OPENAI_MODEL to a model available to the project.
  • Printing the whole environment or key while debugging: never expose credentials.

Try it yourself

Change only the input so the model explains the difference between N and kN in exactly three bullet points. Do not ask it to perform a design calculation.
