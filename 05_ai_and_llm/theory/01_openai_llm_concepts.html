OpenAI Models and LLM Concepts

Learning goals

  • Explain model, token, input, instructions, context, response, and output.
  • Distinguish the OpenAI API from ChatGPT.
  • Identify appropriate and inappropriate engineering uses.

1. What is a large language model?

A large language model, or LLM, processes an input and generates an output by predicting useful sequences of tokens. A token is a small piece of text. It may be a complete word, part of a word, punctuation, or whitespace. Token counts affect how much context fits in a request and how API usage is measured.

A model is good at language tasks such as classification, extraction, summarization, explanation, and drafting. It is not a guaranteed database of facts and it does not automatically verify an engineering formula.

2. OpenAI API and ChatGPT are different products

ChatGPT is an application for people. The OpenAI API is a developer interface used by your Python program. An API request explicitly chooses a model, supplies instructions and input, and receives a response object. API access, billing, project permissions, and rate limits are managed separately from ordinary ChatGPT conversations.

3. Important request concepts

ConceptMeaning
ModelThe OpenAI model that processes the request.
InstructionsHigh-level behavior and rules for the response.
InputThe user content or data supplied to the model.
ContextInformation available to the model for this interaction.
ResponseThe API object containing generated output and metadata.
Output textA convenient combined text representation exposed by the SDK as response.output_text.

4. Why model output can be wrong

The model generates likely output from patterns and supplied context. It can misunderstand a request, omit an assumption, use an incorrect unit, or produce a confident false claim. This failure is often called a hallucination. Better instructions and structured outputs reduce some errors, but do not create mathematical or factual certainty.

5. Safe engineering responsibility split

TaskRecommended component
Understand natural-language intentOpenAI model, followed by validation
Extract candidate values and unitsOpenAI model with Structured Outputs, followed by validation
Calculate stress, pressure, or conversionTested deterministic Python function
Explain a verified resultOpenAI model using supplied verified facts
Approve a consequential designQualified professional and required engineering process
Never ask the model to invent missing dimensions, loads, material properties, units, safety factors, or standards. Missing information must produce a question or refusal.

6. Data and privacy

Before sending information to an API, determine whether the project permits it. Do not send credentials, API keys, personal data, confidential designs, or proprietary measurements without appropriate authorization and controls.
