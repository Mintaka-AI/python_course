Module 5: OpenAI API and LLM Fundamentals

This module introduces large language models through the OpenAI API and the official OpenAI Python SDK. You will send a first request with the Responses API, write clear instructions, request structured output, handle API failures, and keep deterministic engineering calculations outside the model.

Current course interface: examples use the Responses API through from openai import OpenAI. OpenAI products evolve, so each lesson links to the current OpenAI Docs for deeper study and future updates.

Lessons

  1. OpenAI models and LLM concepts
  2. Install the OpenAI SDK and make a first response
  3. Prompting and verified engineering results
  4. Structured Outputs, errors, and safe API boundaries

Examples

  • 01_first_response.py
  • 02_explain_verified_calculation.py
  • 03_structured_measurement.py
  • 04_error_handling.py
  • safe_llm_boundary.py — offline validation example
The API key grants access to an OpenAI project. Never place it in source code, screenshots, JSON reports, or Git. Generated output is not verified engineering evidence.
