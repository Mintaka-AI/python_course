Flexible Arguments, Closures, and Decorators

Prerequisite: know function parameters, return values, local variables, and that functions can be passed as values. These tools are powerful, so use them only when a simpler function is not clearer.

Collecting extra arguments

*args collects extra positional arguments into a tuple. **kwargs collects extra keyword arguments into a dictionary. The names args and kwargs are conventional; the stars have the special meaning.

Syntax

def function_name(required, *args, **kwargs):
    # args is a tuple; kwargs is a dictionary
    pass
def report_readings(agent_name, *readings_c, **metadata):
    print(agent_name, "received", len(readings_c), "readings")
    print("Average:", sum(readings_c) / len(readings_c))
    print("Source:", metadata["source"])

report_readings("Monitor", 20.0, 20.5, 19.8, source="lab-A")

Expected output:

Monitor received 3 readings
Average: 20.1
Source: lab-A

Closures: a function remembers context

A closure is an inner function that keeps access to a value from its outer function, even after the outer function has finished. A closure can make a reusable converter with a fixed calibration value.

def make_calibrator(offset_c):
    def calibrate(raw_c):
        return raw_c + offset_c
    return calibrate

lab_a_calibrate = make_calibrator(0.3)
print(lab_a_calibrate(20.0))

Expected output: 20.3. The returned calibrate function remembers offset_c as 0.3.

Decorators: wrap a function

A decorator receives a function and returns a replacement function. The replacement can add behavior before and after the original function, such as logging an AI-agent tool call. The @decorator_name syntax applies the wrapper.

Syntax

def decorator_name(function):
    def wrapper(*args, **kwargs):
        return function(*args, **kwargs)
    return wrapper

@decorator_name
def original_function():
    pass
def announce(function):
    def wrapper(*args, **kwargs):
        print("Starting calculation")
        result = function(*args, **kwargs)
        print("Calculation finished")
        return result
    return wrapper

@announce
def area_m2(width_m, height_m):
    return width_m * height_m

print(area_m2(3, 2))

Expected output:

Starting calculation
Calculation finished
6
A wrapper that accepts *args, **kwargs can call many different functions. It forwards received arguments with function(*args, **kwargs).
Safety note: never let a decorator hide changes to an engineering result, skip validation, or log sensitive data. Keep safety calculations explicit and test the wrapped function as well as the decorator.
