Packaging and Command-Line Programs

A package is a folder that groups related Python modules. A command-line interface (CLI) lets a person supply program options in a terminal. Together, they help turn a one-file calculation into a small, reusable engineering tool.

Prerequisite: be comfortable with functions, imports, files, and dictionaries. This is an advanced lesson: learn the structure first, then use it in later projects.

A small package layout

Names are examples. The package folder contains code; the outer project folder can also contain tests and documentation.

beam_tool/
├── pyproject.toml
├── beam_tool/
│   ├── __init__.py
│   ├── calculations.py
│   └── cli.py
└── tests/
    └── test_calculations.py

__init__.py marks a traditional Python package. Put the formula in calculations.py and terminal input/output in cli.py. This separation makes the formula easier to test.

CLI syntax with argparse

The standard-library argparse module reads options such as --force. Define the options, parse them, then call a normal function.

import argparse

parser = argparse.ArgumentParser(description="Calculate stress")
parser.add_argument("--force", type=float, required=True)
parser.add_argument("--area", type=float, required=True)
args = parser.parse_args()

stress_pa = args.force / args.area
print(f"Stress: {stress_pa:.1f} Pa")

Run: python cli.py --force 12000 --area 0.006

Expected output: Stress: 2000000.0 Pa

Helpful options

parser.add_argument("--material", default="steel",
                    help="Name shown in the report")
parser.add_argument("--safety-factor", type=float, default=1.5,
                    help="Factor greater than zero")

An option with a default is optional. Use python cli.py --help to see generated help. Use clear names, units, and validation before performing a calculation.

Engineering design rule

Keep deterministic calculations independent from the CLI. A function such as calculate_stress(force_n, area_m2) should return a number and should not call input() or print. The CLI validates text from the user, calls the function, and formats the result.

Warning: command-line values are untrusted input. Check physical limits such as an area greater than zero. Do not silently accept an unknown unit or replace a bad value with zero.
