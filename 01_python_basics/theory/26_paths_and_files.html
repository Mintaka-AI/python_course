Simple Paths and File I/O

A path tells Python where a file is. File I/O means input and output: reading data from a file or writing text to one.

from pathlib import Path

report_path = Path("report.txt")
with report_path.open("w", encoding="utf-8") as report_file:
    report_file.write("Load: 1200 N\n")

print(report_path.exists())

Expected output: True. The code creates report.txt beside the program. with closes the file when its indented block ends, even if an error occurs.

from pathlib import Path

report_path = Path("report.txt")
with report_path.open(encoding="utf-8") as report_file:
    report_text = report_file.read()

print(report_text)

Expected output: Load: 1200 N on its own line, if the first example created the file.

Use a relative path such as Path("report.txt") for a small project. Do not assume a file exists or accept an untrusted path without validation.
