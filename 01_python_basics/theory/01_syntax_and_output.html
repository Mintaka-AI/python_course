Python Syntax, Comments, and Output

Write a small Python program, run it in UCRT64, and read its output.

Run a Python file in UCRT64

Save your code in a file ending in .py, for example force_check.py. Open the MSYS2 UCRT64 terminal in that folder and run:

python force_check.py

python starts the UCRT64 Python interpreter and the file name tells it which program to run. Check the interpreter first with python --version if a command does not work.

Keep one terminal environment. This course uses MSYS2 UCRT64. Do not switch between several Python installations while learning, because packages and versions can differ.

Statements and expressions

Python reads a program from top to bottom. A statement tells Python to do something. An expression produces a value.

force_n = 1_200       # assignment statement
area_m2 = 0.02        # assignment statement
stress_pa = force_n / area_m2  # division expression

print(stress_pa)      # function-call statement

Here, force_n / area_m2 is an expression: it produces 60000.0. The whole line that stores it in stress_pa is a statement.

Print output

print() displays text and values in the terminal. Separate items with commas; Python places a space between them.

print("Calculation started")
force_n = 1_200
print(force_n)
print("Force:", force_n, "N")

Expected output:

Calculation started
1200
Force: 1200 N

The first line prints text. The second prints the number. The final call combines text, the value, and its unit.

Comments and indentation

A comment starts with #. Python ignores it. Use comments to explain a calculation choice or a unit conversion.

# Convert kilonewtons to newtons before calculating stress.
force_n = 12.5 * 1_000

Indentation is the spaces at the beginning of a line. Later, it groups code under if, loops, and functions. Use four spaces for each level.

Indentation matters. Do not mix tabs and spaces. A missing or extra indentation can cause an IndentationError.

When Python reports an error

A traceback is Python's error report. Read the last line first: it gives the error type and a short reason. The lines above help you locate the file and line.

File "force_check.py", line 2
    print(force_n
         ^
SyntaxError: '(' was never closed

This report says that line 2 has an opening parenthesis without a closing one. Fix that line, save the file, and run it again.
