Python for Loops

A for loop repeats a block once for every item in a sequence. It is useful when you have a known group of sensor readings, test numbers, or distances.

Loop through a list

loads_kn = [12.5, 14.0, 11.8]

for load_kn in loads_kn:
    print(f"Load: {load_kn} kN")

Expected output: three lines: Load: 12.5 kN, Load: 14.0 kN, and Load: 11.8 kN. On each pass, load_kn holds the next list value.

Use range()

range(stop) makes integers from 0 up to, but not including, stop. Its full form is range(start, stop, step).

for test_number in range(1, 4):
    print(f"Test {test_number}")

for distance_m in range(0, 101, 25):
    print(f"Position: {distance_m} m")

Expected output: the first loop prints Tests 1, 2, and 3. The second prints positions 0, 25, 50, 75, and 100 m. The stop value is not included.

break and continue

break ends the whole loop immediately. continue skips the remaining code for the current item and moves to the next item.

measurements_c = [20.0, -999, 21.5, 150.0, 22.1]

for temperature_c in measurements_c:
    if temperature_c == -999:
        print("Missing reading: skipped")
        continue
    if temperature_c > 100:
        print("Unsafe temperature: stopping")
        break
    print(f"Accepted: {temperature_c} °C")

Expected output: 20.0 °C is accepted, the missing reading is skipped, 21.5 °C is accepted, then the unsafe value stops the loop. 22.1 °C is never reached.

Loop else

An else attached to a loop runs only when the loop finishes normally. It does not run if break ends the loop.

pressures_bar = [4.8, 5.1, 4.9]

for pressure_bar in pressures_bar:
    if pressure_bar > 6.0:
        print("Pressure limit exceeded")
        break
else:
    print("All pressure readings are within the limit.")

Expected output: All pressure readings are within the limit. prints because no reading is above 6.0 and no break occurs.

Nested loops

A nested loop is a loop inside another loop. The inner loop completes for every outer-loop item. Use this for a small grid of test cases.

materials = ["Aluminium", "Steel"]
thicknesses_mm = [2, 4]

for material in materials:
    for thickness_mm in thicknesses_mm:
        print(f"Test {material}, {thickness_mm} mm")

Expected output: four test labels: two thicknesses for Aluminium, then two for Steel.

Use meaningful singular names inside a loop: for load_kn in loads_kn. This makes code easier to read.
Do not change a list's size while you are looping through it. Create a new list or loop over a copy when items must be removed.
