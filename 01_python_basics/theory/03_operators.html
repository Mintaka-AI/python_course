Python Operators

Use operators to calculate values, compare limits, and update measurements.

Arithmetic operators

Arithmetic operators form numeric expressions: + add, - subtract, * multiply, / divide, // floor division, % remainder, and ** power.

force_n = 1_200
area_m2 = 0.02
stress_pa = force_n / area_m2
radius_m = 0.5
circle_area_m2 = 3.14159 * radius_m ** 2

print(stress_pa)
print(circle_area_m2)

Expected output is 60000.0 and about 0.7853975. The exponent radius_m ** 2 calculates radius squared.

Comparison and logical operators

Comparisons return a Boolean value: ==, !=, <, >, <=, and >=. Combine checks with and (both true), or (at least one true), and not (reverse a Boolean).

temperature_c = 22
pressure_bar = 5
is_operating_safely = temperature_c <= 80 and pressure_bar <= 10

print(is_operating_safely)

The expected output is True because both limit checks are true.

Assignment operators

= assigns a value. Operators such as +=, -=, *=, and /= calculate and store a new value in the same variable.

distance_m = 100
distance_m += 25
distance_m *= 2
print(distance_m)

Expected output: 250. This is equivalent to adding 25 to distance_m, then multiplying its new value by 2.

Operator precedence

Python usually evaluates parentheses first, then powers, then multiplication and division, then addition and subtraction. Use parentheses when the calculation should be obvious to a reader.

mass_kg = 10
acceleration_m_s2 = 2
force_n = mass_kg * (acceleration_m_s2 + 9.80665)

print(force_n)

Expected output: 118.0665. The parentheses make Python add the accelerations before multiplying by mass.

= assigns a value; == compares two values. In formulas, use parentheses instead of guessing the evaluation order.

Try it yourself

Store a box length, width, and height in metres. Calculate and print its volume. Then use *= to double the volume and print whether the doubled volume is greater than 10.
