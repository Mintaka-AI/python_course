Variables, Data Types, and Casting

Store engineering values with meaningful names and use the right kind of value.

Variables and assignment

A variable is a name that refers to a value. Create one with =; this is called assignment. A later assignment replaces its old value.

length_m = 2.5
length_m = 3.0
print(length_m)

Expected output: 3.0. Python uses the latest value assigned to length_m.

Use snake_case: lower-case words separated by underscores. Include units in physical names, for example pressure_pa, mass_kg, and length_m.

Variable naming rules

  • Names may contain letters, digits, and underscores, but cannot begin with a digit.
  • Spaces and hyphens are not allowed.
  • Names are case-sensitive: force_n and Force_n differ.
  • Do not use Python keywords such as if, for, or def.

Text and f-strings

A string is text inside single or double quotes. An f-string starts with f and inserts a value inside braces.

material = "Aluminium"
density_kg_m3 = 2700

print(f"Material: {material}")
print(f"Density: {density_kg_m3} kg/m³")

Expected output includes Material: Aluminium and Density: 2700 kg/m³. The expressions inside {} are evaluated before printing.

Convert values deliberately

int(), float(), str(), and bool() convert values. For example, int(12.9) gives 12; it removes the decimal part rather than rounding it.

whole_value = int(12.9)
decimal_value = float(12)
text_value = str(12)

print(whole_value)
print(decimal_value)
print(text_value)

Truthiness and float precision

In a Boolean context, zero, an empty string, and None are false-like. Most other values are true-like.

print(bool(0))
print(bool(""))
print(bool(5))

Expected output is False, False, then True.

Decimal values are approximations. Computers store many floats approximately, so 0.1 + 0.2 == 0.3 can be False. Round displayed values with round(value, 2); do not rely on exact float equality in measurements.

Runnable engineering example

STANDARD_GRAVITY_M_S2 = 9.80665
mass_kg = 12.5
weight_n = mass_kg * STANDARD_GRAVITY_M_S2

print(f"Mass: {mass_kg} kg")
print(f"Weight: {weight_n:.2f} N")

Expected output ends with Weight: 122.58 N. The :.2f part displays the float with two decimal places.
