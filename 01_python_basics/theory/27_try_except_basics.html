Basic Error Handling with try and except

An exception is an error signal raised while a program runs. Use try and except when an expected outside value, such as typed text, may be invalid.

force_text = "not a number"

try:
    force_n = float(force_text)
except ValueError:
    print("Enter a number for force.")
else:
    print(f"Force: {force_n} N")

Expected output: Enter a number for force.. The else block runs only if converting the text succeeds.

from pathlib import Path

try:
    text = Path("missing.txt").read_text(encoding="utf-8")
except FileNotFoundError:
    print("The measurement file was not found.")

Expected output: The measurement file was not found., unless a file named missing.txt exists.

Catch a specific exception such as ValueError or FileNotFoundError. A bare except: can hide programming mistakes. Module 2 covers validation, finally, raising errors, type hints, and pytest in depth.
