Async, Await, and asyncio

Asynchronous Python lets one program make progress on other waiting tasks. It does not turn a slow numerical calculation into a faster calculation; it is mainly useful when a task spends time waiting.

Prerequisite: understand functions and the concurrency ideas in lesson 22. Use asynchronous code only when you have several independent waiting tasks and an async-capable library.

Three new words

async def defines a coroutine function. Calling it creates a coroutine object; it does not immediately run all its code. await pauses that coroutine while another ready coroutine can run. asyncio.run() starts the event loop for a top-level program.

import asyncio

async def inspect_part(part_id):
    await asyncio.sleep(0.1)  # simulated wait
    return f"{part_id}: complete"

async def main():
    result = await inspect_part("P-01")
    print(result)

asyncio.run(main())

Expected output: P-01: complete. The sleep is only a safe simulation; no external service is contacted.

Start independent tasks together

import asyncio

async def inspect_part(part_id):
    await asyncio.sleep(0.1)
    return f"{part_id}: complete"

async def main():
    reports = await asyncio.gather(
        inspect_part("P-01"),
        inspect_part("P-02"),
        inspect_part("P-03"),
    )
    for report in reports:
        print(report)

asyncio.run(main())

Expected output: three lines, from P-01: complete through P-03: complete. asyncio.gather() waits for all supplied awaitables. Its returned list follows the input order, even when individual tasks finish in a different order.

Keep calculations ordinary and deterministic

Do numerical work in normal, testable functions. An async function can await a simulated or real waiting operation and then pass validated numbers to the calculation.

import asyncio

def pressure_pa(force_n, area_m2):
    return force_n / area_m2

async def inspect_then_calculate():
    await asyncio.sleep(0.1)
    return pressure_pa(12000, 0.006)

print(asyncio.run(inspect_then_calculate()))

Expected output: 2000000.0.

Warning: do not call blocking work such as time.sleep(), a long CPU loop, or ordinary blocking I/O directly inside an async function. It stops the event loop and prevents other coroutines from running. Also handle timeouts and failures when real I/O is introduced.
