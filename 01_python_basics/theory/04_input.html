User Input and Type Conversion

Ask a user for a value, convert it safely, and use it in a calculation.

Use input()

input(prompt) prints a prompt, pauses the program, and returns what the user typed. The returned value is always text, also called a str.

material = input("Material name: ")
print(f"Selected material: {material}")

If the user types Steel, the expected output is Selected material: Steel.

Convert numeric input

A calculation needs numbers, not text. Use int() for a whole number and float() for a decimal measurement.

force_text = input("Force in N: ")
force_n = float(force_text)
area_m2 = 0.02
stress_pa = force_n / area_m2

print(f"Stress: {stress_pa:.2f} Pa")

With input 1200, the expected final output is Stress: 60000.00 Pa. Separating the text and number variables makes the conversion clear.

Safe input habits

Write prompts that include the expected unit. Before using a measurement, consider whether it is empty, numeric, and physically meaningful. For example, an area used as a divisor must be greater than zero.

area_text = input("Area in m² (greater than 0): ").strip()

if area_text:
    area_m2 = float(area_text)
    print(f"Received: {area_m2} m²")
else:
    print("No area was entered.")

strip() removes spaces at the start and end. The condition prevents conversion when the user only presses Enter. Conditions are explained in the next lesson.

Entering ten into float() raises ValueError; entering 0 for an area can later cause division by zero. Do not use unverified input for a real engineering decision. Full error handling comes later.

Runnable engineering example

length_m = float(input("Length in m: "))
length_mm = length_m * 1_000

print(f"Length: {length_mm:.1f} mm")

When the user enters 2.5, the program prints Length: 2500.0 mm. The f-string formats the result to one decimal place.

Keep raw input and converted values separate while learning: names such as length_text and length_m show what each value contains.

Try it yourself

Ask for a mass in kilograms, convert it to float, calculate the weight using 9.80665, and print the result in newtons with two decimal places. Include the unit in the prompt.
