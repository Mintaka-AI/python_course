Imports and Modules

A module is a Python file containing reusable code. An import lets your program use names from that file or from Python's standard library.

import math

radius_m = 0.5
circle_area_m2 = math.pi * radius_m ** 2
print(f"Area: {circle_area_m2:.3f} m²")

Expected output: Area: 0.785 m². math.pi means the name pi inside the math module.

from math import sqrt

length_m = sqrt(9)
print(length_m)

Expected output: 3.0. This form imports one named tool. Prefer clear imports; avoid from module import * because it hides where names came from.
