Functions, Parameters, and Return Values

A function is a named, reusable block of code. Define it with def, then call it using its name.

def rectangle_area(length_m, width_m):
    return length_m * width_m


area_m2 = rectangle_area(2.5, 1.2)
print(f"Area: {area_m2} m²")

length_m and width_m are parameters. return sends the calculation result back to the caller.

Expected output: Area: 3.0 m². The function calculates first; print() displays the returned value.

Docstrings

A docstring is the first string inside a function. It explains what the function does, its inputs, and its result. Python tools can show it with help().

def cylinder_volume_m3(radius_m, height_m):
    """Return the volume of a cylinder in cubic metres."""
    return 3.14159 * radius_m ** 2 * height_m

print(cylinder_volume_m3(0.5, 2.0))

Expected output: approximately 1.570795. The triple-quoted text is documentation, not output.

Positional and keyword arguments

Positional arguments match parameters by order. Keyword arguments name the parameter, so their order is clear to the reader.

def pressure_pa(force_n, area_m2):
    """Return pressure in pascals."""
    return force_n / area_m2

print(pressure_pa(1000, 2))                 # positional
print(pressure_pa(area_m2=2, force_n=1000)) # keyword

Expected output: both calls print 500.0. Keyword arguments prevent confusion about which value is force and which is area.

Default parameter

A default parameter is used when the caller does not provide that value.

def convert_length(value_m, factor=1000):
    return value_m * factor


print(convert_length(2.5))
print(convert_length(2.5, 100))

Expected output: 2500.0 then 250.0. The first call uses the default factor of 1000; the second supplies 100.

Local and global scope

A variable created inside a function is local: it exists only inside that function. A global variable is defined outside. Reading a global is possible, but passing values and returning results is usually safer.

unit = "kN"  # global variable

def show_load(load_kn):
    label = f"{load_kn} {unit}"  # local variable
    print(label)

show_load(12.5)
print(unit)

Expected output: 12.5 kN then kN. label cannot be used outside show_load.

Use functions to keep one calculation in one place. This makes later testing and correction much safer.
Do not use a mutable value such as [] as a default parameter. Create the list inside the function when needed; this avoids sharing one list between calls.
