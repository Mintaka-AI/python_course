Python while Loops

A while loop repeats while its condition is True. Use it when repetition depends on a changing condition, not simply on every item in a list.

A counter with a clear end

pressure_bar = 0
maximum_pressure_bar = 5

while pressure_bar <= maximum_pressure_bar:
    print(f"Pressure: {pressure_bar} bar")
    pressure_bar = pressure_bar + 1

Expected output: pressure values from 0 through 5 bar. After printing 5, the counter becomes 6, so the condition is false and the loop stops.

Safe termination

Every while loop needs a path to a false condition. A counter, a maximum number of attempts, or a changed measurement can provide that path.

target_temperature_c = 60
temperature_c = 20
step = 0
maximum_steps = 10

while temperature_c < target_temperature_c and step < maximum_steps:
    temperature_c += 5
    step += 1
    print(f"Step {step}: {temperature_c} °C")

if temperature_c >= target_temperature_c:
    print("Target reached.")
else:
    print("Stopped after the safe step limit.")

Expected output: eight heating steps end at 60 °C, followed by Target reached.. The maximum-step check prevents accidental endless repetition if the temperature never rises.

Validate user input

diameter_mm = float(input("Diameter in mm: "))

while diameter_mm <= 0:
    print("Diameter must be greater than zero.")
    diameter_mm = float(input("Diameter in mm: "))

print(f"Accepted: {diameter_mm} mm")

Expected output: invalid zero or negative values show the message and ask again. A positive value exits the loop and prints the accepted diameter.

break, continue, and else

You can use break, continue, and loop else with while too.

attempt = 1
maximum_attempts = 3

while attempt <= maximum_attempts:
    reading = 4.5 + attempt
    if reading > 6.0:
        print(f"Limit found on attempt {attempt}")
        break
    attempt += 1
else:
    print("No limit was found.")

Expected output: attempt 1 gives 5.5, then attempt 2 gives 6.5 and prints Limit found on attempt 2. The else does not run because break was used.

For a fixed number of repetitions, a for loop with range() is often clearer. Use while when the condition is the important part.
Never write while True unless the loop has a reliable break condition. During learning, prefer a visible limit such as maximum_attempts.
