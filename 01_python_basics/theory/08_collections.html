Python Data Structures

Data structures store several values in one variable. Python’s main built-in structures are strings, lists, tuples, sets, and dictionaries.

Choose the right structure

TypeExampleOrderedChangeableDuplicatesBest use
String"Steel"YesNoYesText
List[12.5, 14.0]YesYesYesMeasurements that may change
Tuple(2.0, 4.5)YesNoYesFixed values, such as coordinates
Set{101, 102}NoYesNoUnique values
Dictionary{"name": "Steel"}Yes*YesKeys: noNamed properties

* Dictionaries preserve insertion order in modern Python, but you normally use them to look up values by key.

1. Strings

A string is text in quotes. It is a sequence of characters, so it supports indexing and slicing. Strings are immutable: methods return new text instead of changing the original.

material = "Structural Steel"

print(material[0])          # S
print(material[0:10])       # Structural
print(material.lower())     # structural steel
print(material.replace(" ", "_"))

Useful string methods: lower(), upper(), strip(), replace(old, new), split(separator), join(values), startswith(text), and endswith(text).

2. Lists

A list is ordered and changeable. It is the usual choice for a sequence of measurements.

temperatures_c = [18.2, 19.0, 20.1]

print(temperatures_c[0])    # first value
print(temperatures_c[-1])   # last value
print(temperatures_c[1:])   # from index 1 to the end

temperatures_c.append(21.4)
temperatures_c[0] = 18.5
print(temperatures_c)

Copy a list safely

Assignment does not make a new list. It gives two variable names to the same list. Use .copy(), slicing, or list() when you need an independent copy.

original_loads_kn = [12.5, 14.0, 11.8]
same_loads = original_loads_kn
copied_loads = original_loads_kn.copy()

same_loads.append(15.2)
copied_loads.append(10.0)

print(original_loads_kn)
print(copied_loads)

Expected output: the original becomes [12.5, 14.0, 11.8, 15.2] because same_loads refers to it. The copied list ends with 10.0 instead.

Common list methods

  • append(value) — add one item at the end.
  • extend(values) — add every item from another collection.
  • insert(index, value) — add an item at a position.
  • remove(value) — remove the first matching value.
  • pop(index) — remove and return an item; no index means the last item.
  • sort() and reverse() — change the list order.
  • count(value) and index(value) — find occurrences or a position.
  • clear() — remove every item.
sort(), reverse(), and clear() change the original list. Use sorted(values) to create a sorted copy instead.

3. Tuples

A tuple is ordered but cannot be changed after creation. Use a tuple for data that must stay fixed, such as an (x, y) coordinate.

sensor_location_m = (2.0, 4.5)
x_m, y_m = sensor_location_m

print(x_m)
print(sensor_location_m.count(2.0))
print(sensor_location_m.index(4.5))

The main tuple methods are count(value) and index(value). A one-item tuple needs a comma: one_value = (5,).

4. Sets

A set stores unique items. It is useful for removing duplicate sensor IDs or comparing groups of values. A set has no index, so sensor_ids[0] is invalid.

sensor_ids = {101, 102, 101, 103}
required_ids = {101, 102, 104}

sensor_ids.add(105)
sensor_ids.discard(103)

print(sensor_ids)
print(sensor_ids & required_ids)  # items in both sets
print(sensor_ids | required_ids)  # all unique items
print(required_ids - sensor_ids)  # missing IDs

Useful set methods: add(value), update(values), remove(value), discard(value), union(other), intersection(other), and difference(other). remove() raises an error for a missing item; discard() does not.

5. Dictionaries

A dictionary connects unique keys to values. It is ideal for material properties, settings, or one measurement record.

steel = {
    "name": "Structural steel",
    "density_kg_m3": 7850,
    "yield_strength_mpa": 250,
}

print(steel["density_kg_m3"])
steel["density_kg_m3"] = 7900
steel["is_recyclable"] = True

for key, value in steel.items():
    print(f"{key}: {value}")

Common dictionary methods

  • get(key, default) — safely get a value; returns the default if the key is absent.
  • keys(), values(), items() — views for looping.
  • update(other) — add or update several key-value pairs.
  • pop(key) — remove and return a value.
  • setdefault(key, default) — get a value, adding the default when the key is missing.
limit_mpa = steel.get("limit_mpa", 250)
print(limit_mpa)

6. Built-in functions for collections

These functions work with many data structures:

loads_kn = [12.5, 14.0, 11.8]

print(len(loads_kn))
print(min(loads_kn))
print(max(loads_kn))
print(sum(loads_kn))
print(sorted(loads_kn))

for index, load_kn in enumerate(loads_kn, start=1):
    print(index, load_kn)

Also useful: list(values), tuple(values), set(values), dict(pairs), reversed(values), any(values), and all(values).

Match values with zip()

zip() pairs items at the same position from two or more collections. This is useful when labels and readings are stored separately.

sensor_names = ["A1", "A2", "A3"]
temperatures_c = [20.1, 21.4, 19.8]

for sensor_name, temperature_c in zip(sensor_names, temperatures_c):
    print(f"{sensor_name}: {temperature_c} °C")

Expected output: each sensor is printed with the temperature at the same position. zip() stops when the shortest collection ends.

Check conditions with any() and all()

pressures_bar = [4.8, 5.1, 6.3]
over_limit = [pressure_bar > 6.0 for pressure_bar in pressures_bar]

print(any(over_limit))
print(all(pressure_bar > 0 for pressure_bar in pressures_bar))

Expected output: True then True. At least one pressure exceeds 6.0, and every pressure is positive. The list expression is introduced fully in Lesson 12.

7. Looping through structures

for temperature_c in [18.2, 19.0, 20.1]:
    print(temperature_c)

for character in "Pa":
    print(character)

for property_name, property_value in steel.items():
    print(property_name, property_value)
Lists, dictionaries, and sets are mutable: their contents can change. Strings and tuples are immutable. Choose the type that matches the data and the changes you expect.
A list copy made with .copy() is a shallow copy. It is enough for a simple list of numbers, but nested lists need more care later.
