Iterators and Generators

Prerequisite: you should understand lists, for loops, functions, and comprehensions. This lesson explains what a for loop does behind the scenes.

When an AI agent processes many sensor readings, it may not need every value in memory at once. Iterators and generators provide values one at a time. This is called lazy processing.

Iterable, iterator, and the iterator protocol

An iterable is an object you can loop over, such as a list, string, tuple, dictionary, or range. An iterator is the object that remembers the current position while values are being read.

Use iter(iterable) to create an iterator. Use next(iterator) to request one value. When no values remain, next() raises StopIteration. A for loop handles this stop signal for you.

Syntax

iterator = iter(iterable)
value = next(iterator)
readings_c = [19.5, 20.1, 20.4]
reading_iterator = iter(readings_c)

print(next(reading_iterator))
print(next(reading_iterator))
print(next(reading_iterator))

Expected output:

19.5
20.1
20.4

Do not call next(reading_iterator) a fourth time here: it would raise StopIteration.

Generators with yield

A generator function looks like a normal function, but it uses yield instead of returning all results at once. Calling it creates a generator iterator; its body begins only when you ask for a value. Each yield sends a value out and pauses the function until the next request.

Syntax

def generator_name(values):
    for value in values:
        yield transformed_value
def loads_in_newtons(loads_kn):
    for load_kn in loads_kn:
        yield load_kn * 1_000

for load_n in loads_in_newtons([2.5, 4.0, 3.2]):
    print(f"{load_n:.0f} N")

Expected output:

2500 N
4000 N
3200 N

Generator expressions

A generator expression is the lazy version of a list comprehension. It uses parentheses, not square brackets. It is useful when you need to pass values through one time, for example to sum().

loads_kn = [2.5, 4.0, 3.2]
loads_n = (load_kn * 1_000 for load_kn in loads_kn)

print(sum(loads_n))
print(list(loads_n))

Expected output:

9700.0
[]

The generator is exhausted after sum(). Create a new generator if you need to read the values again.

Use a list when you need to index, reuse, or inspect all values. Use a generator when values can be processed once, especially for a large stream of measurements.
Safety note: generators do not make invalid readings safe. Validate units, ranges, and missing data before using a generated value for an engineering decision. Also remember that an exhausted iterator silently has no more data.
