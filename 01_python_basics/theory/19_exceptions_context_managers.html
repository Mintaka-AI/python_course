Exceptions and Context Managers

Lesson 19 · Report invalid conditions and always clean up resources

Prerequisite: know functions, classes, and the basic try/except pattern. Exceptions are signals for unusual conditions; they are not a replacement for normal if decisions.

Make domain errors clear

A custom exception gives an engineering problem a specific name. Usually inherit from the closest built-in exception. Invalid numeric input commonly fits ValueError.

class InvalidPressureError(ValueError):
    """Raised when a pressure is not physically valid."""

def pressure_ratio(actual_kpa: float, limit_kpa: float) -> float:
    if actual_kpa < 0:
        raise InvalidPressureError("Pressure cannot be negative.")
    if limit_kpa <= 0:
        raise InvalidPressureError("Pressure limit must be greater than zero.")
    return actual_kpa / limit_kpa

Expected behavior: pressure_ratio(180.0, 250.0) returns 0.72. A negative pressure raises a readable InvalidPressureError.

Catch only what you can handle

try:
    ratio = pressure_ratio(-5.0, 250.0)
except InvalidPressureError as error:
    print(f"Input error: {error}")
else:
    print(f"Ratio: {ratio:.2f}")
finally:
    print("Check completed.")

except handles the chosen error. else runs only on success. finally runs whether success or failure occurs.

Context managers and with

A context manager prepares a resource and reliably cleans it up. The common file form closes a file even if an error occurs:

with open("readings.txt", encoding="utf-8") as file:
    text = file.read()
# The file is closed here.

You can create a small context manager with contextlib.contextmanager. Code before yield is setup; code in finally is cleanup.

from contextlib import contextmanager

@contextmanager
def test_section(name: str):
    print(f"Starting {name}")
    try:
        yield
    finally:
        print(f"Finished {name}")
Warning: do not write except Exception: pass. It hides bugs, including programming mistakes. Catch the narrow expected exception, explain it, and let unexpected errors be visible while developing.

Engineering example

The matching example opens a named test section, calculates a valid pressure ratio, deliberately handles a negative measurement, and always prints its cleanup line.

python examples/19_exceptions_context_managers.py

Expected output: it begins with Starting pressure check, reports a ratio of 0.72, prints the input error, then ends with Finished pressure check.
