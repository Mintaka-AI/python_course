Lambda and Higher-Order Functions

Prerequisite: you should be comfortable defining functions, using lists, and writing for loops. A normal named function is still the best first choice for multi-step work.

A function can be stored in a variable, passed to another function, or returned from one. A function that receives or returns another function is a higher-order function. This is useful when an AI agent needs a small, configurable rule for sorting or transforming data.

Lambda expressions

A lambda is a small anonymous function written on one expression. It automatically returns that expression's value. It cannot contain assignments, loops, or multiple statements.

Syntax

lambda parameter: expression
lambda first, second: expression
area_of_square = lambda side_m: side_m ** 2

print(area_of_square(3.0))

Expected output: 9.0. The lambda receives 3.0 and evaluates 3.0 ** 2.

map() and filter()

map(function, iterable) applies a function to each item. filter(function, iterable) keeps values for which the function returns True. Both return lazy iterators, so use list() when you want to display their results.

temperatures_c = [-3, 5, 18]
temperatures_f = list(map(lambda temp_c: temp_c * 9 / 5 + 32, temperatures_c))
above_freezing_c = list(filter(lambda temp_c: temp_c >= 0, temperatures_c))

print(temperatures_f)
print(above_freezing_c)

Expected output:

[26.6, 41.0, 64.4]
[5, 18]

For many beginners, a comprehension is clearer than map() or filter(). Compare: [temp_c for temp_c in temperatures_c if temp_c >= 0].

Sorting with a key function

sorted() can use key= to decide what to compare. The key function receives one item and returns its sorting value.

tests = [
    {"id": "T-1", "error_mm": 0.8},
    {"id": "T-2", "error_mm": 0.2},
    {"id": "T-3", "error_mm": 0.5},
]

sorted_tests = sorted(tests, key=lambda test: test["error_mm"])
print([test["id"] for test in sorted_tests])

Expected output: ['T-2', 'T-3', 'T-1'].

Use lambda for a short, obvious rule used once, such as a sorted(key=...) expression. Give repeated or complex work a descriptive def name.
Safety note: a compact lambda can hide an important engineering rule. Do not put safety limits, unit conversions, or complicated validation into an unreadable one-line expression; use a named function and test it.
