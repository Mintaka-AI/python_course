Comprehensions: an Advanced Preview

A comprehension is a short way to build a collection from another collection. It is useful, but a regular for loop is often easier to learn and debug. This page is a preview, not a requirement to memorize.

From a loop to a list comprehension

loads_kn = [2, 4, 6]
loads_n = []

for load_kn in loads_kn:
    loads_n.append(load_kn * 1000)

print(loads_n)

Expected output: [2000, 4000, 6000]. The loop builds a new list one converted value at a time.

loads_kn = [2, 4, 6]
loads_n = [load_kn * 1000 for load_kn in loads_kn]

print(loads_n)

Expected output: the same list, [2000, 4000, 6000]. Read the expression as: “make load_kn * 1000 for each load_kn in loads_kn.”

Filter with an if condition

temperatures_c = [-5, 8, 20, -2, 15]
above_freezing_c = [
    temperature_c
    for temperature_c in temperatures_c
    if temperature_c >= 0
]

print(above_freezing_c)

Expected output: [8, 20, 15]. Only values meeting the condition become items in the new list.

Set and dictionary comprehensions

sensor_ids = ["A1", "A2", "A1", "A3"]
unique_sensor_ids = {sensor_id for sensor_id in sensor_ids}

loads_kn = [2, 4, 6]
load_by_test = {
    test_number: load_kn
    for test_number, load_kn in enumerate(loads_kn, start=1)
}

print(unique_sensor_ids)
print(load_by_test)

Expected output: the set contains A1, A2, and A3 once each (its display order may differ). The dictionary is {1: 2, 2: 4, 3: 6}.

Comprehensions are best when the operation is short and obvious. Keep the normal loop version when it communicates the work more clearly.
Avoid deeply nested comprehensions and complicated conditions at this stage. They can be difficult to read, explain, and debug.
