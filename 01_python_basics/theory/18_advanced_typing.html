Advanced Type Hints

Lesson 18 · Describe the shape of data before it causes confusion

Prerequisite: know functions, classes, dictionaries, and basic hints such as float and str. Type hints document intent and help a type checker, but Python does not enforce them automatically at runtime.

Built-in generic types

Put the item type in square brackets. This tells a reader what a collection should contain.

temperatures_c: list[float] = [21.5, 22.0]
limits: dict[str, float] = {"pressure_kpa": 250.0}

def average(values: list[float]) -> float:
    return sum(values) / len(values)

Expected result: a reader knows that average accepts floating-point readings and returns one float.

Optional, Union, and Literal

Use Optional[T] when a value can be T or None. Use Union for one of several types, and Literal for a small fixed set of exact values.

from typing import Literal, Optional, Union

measured_pressure_kpa: Optional[float] = None
sensor_value: Union[int, float] = 12.5
test_status: Literal["pass", "fail"] = "pass"

Expected result: measured_pressure_kpa may be absent, sensor_value may be an integer or float, and a type checker can reject a status other than "pass" or "fail".

TypedDict: a dictionary with named expected keys

Use TypedDict when a dictionary is useful, for example after reading JSON, but its expected keys deserve documentation.

from typing import TypedDict

class SensorRecord(TypedDict):
    sensor_id: str
    temperature_c: float

record: SensorRecord = {"sensor_id": "T-01", "temperature_c": 21.5}

A type checker can report a missing temperature_c key or a text value where a float is expected.

Protocol: describe ability, not ancestry

A Protocol says what attributes or methods an object needs. Any object with that shape fits; it does not need to inherit from a particular parent class.

from typing import Protocol

class HasMass(Protocol):
    mass_kg: float

def total_mass(items: list[HasMass]) -> float:
    return sum(item.mass_kg for item in items)

A SteelPlate and a Motor can both be accepted if each has a mass_kg attribute.

Abstract base classes: require a shared method

A protocol is structural: an object fits when it has the right shape. An abstract base class (ABC) is a parent class that deliberately requires subclasses to provide a method.

from abc import ABC, abstractmethod

class LoadCase(ABC):
    @abstractmethod
    def force_n(self) -> float:
        """Return the force for this load case."""

class StaticLoad(LoadCase):
    def force_n(self) -> float:
        return 1_200.0

print(StaticLoad().force_n())

Expected output: 1200.0. Python prevents creating a LoadCase subclass that does not implement force_n().

Generics: retain the caller's type

A generic function uses a type variable as a placeholder. It means “the output has the same type as the input item.”

from typing import TypeVar

T = TypeVar("T")

def first_reading(values: list[T]) -> T:
    return values[0]

Expected output: with list[int], the result is an int; with list[SensorRecord], it is a SensorRecord.

Warning: hints do not convert values and do not validate user input. load_kn: float = "heavy" still runs until an operation fails. Validate outside data and use tests; a static type checker is an additional tool.
