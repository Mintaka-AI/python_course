if, elif, and else

Choose an action when a measurement passes, approaches, or exceeds a limit.

Make a decision with if

A condition is an expression that becomes True or False. An if statement runs its indented block only when the condition is true. End the condition with a colon.

stress_mpa = 180
limit_mpa = 250

if stress_mpa <= limit_mpa:
    print("Within the limit")
else:
    print("Exceeds the limit")

The expected output is Within the limit because 180 is less than or equal to 250. Exactly one of these two branches runs.

Add choices with elif

Use elif for an additional condition. Python checks from top to bottom and runs only the first matching branch.

temperature_c = 85

if temperature_c < 0:
    print("Below freezing")
elif temperature_c <= 80:
    print("Normal operating range")
else:
    print("Temperature too high")

The expected output is Temperature too high. The first two checks are false, so Python runs else.

Put the most specific or restrictive checks first when conditions overlap. For example, check an emergency limit before a normal operating limit.

Nested conditions

A nested condition is an if inside another branch. Use it when the second decision only matters after the first one has passed. Each new level needs four more spaces.

pressure_bar = 8
temperature_c = 75

if pressure_bar <= 10:
    if temperature_c <= 80:
        print("Operating within both limits")
    else:
        print("Pressure is safe, but temperature is high")
else:
    print("Pressure is too high")

The expected output is Operating within both limits. First the program checks pressure, then it checks temperature because the pressure is acceptable.

Combine checks when appropriate

For a simple two-limit decision, one condition with and can be clearer than nesting.

pressure_bar = 8
temperature_c = 75

if pressure_bar <= 10 and temperature_c <= 80:
    print("Operating within both limits")
else:
    print("Check operating conditions")

This produces the same expected output as the nested example for these values.

Indentation defines a branch. Use four spaces consistently. Also remember that = assigns; conditions use comparison operators such as == and <=.
