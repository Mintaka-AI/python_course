Strings and f-strings

Prerequisite: lesson 8 introduced strings as a collection type; this lesson expands that topic after lesson 9 so you can also format function results. Engineers use strings for labels, units, file names, and clear messages.

For the short strings introduction, see lesson 8: Data structures. This lesson is the single detailed reference for string methods and f-strings.

Read text and make new text

Strings are immutable: you cannot change one character in place. String methods return a new string instead.

material = "  Structural Steel  "

clean_material = material.strip()
print(clean_material)
print(clean_material.lower())
print(clean_material.replace(" ", "_"))
print(clean_material.startswith("Structural"))

Expected output: Structural Steel, then lowercase text, then Structural_Steel, then True. strip() removes outer spaces; it does not modify material.

Split and join values

sensor_line = "A1,20.5,OK"
parts = sensor_line.split(",")

print(parts)
print(f"Sensor {parts[0]} measured {parts[1]} °C")
print(" | ".join(parts))

Expected output: a three-item list, a readable sensor message, and A1 | 20.5 | OK. split() breaks text into a list; join() combines string items.

Format values with f-strings

Put f before a string to insert values inside braces. You can also control how numbers are displayed.

load_n = 1234.567
area_m2 = 0.25
pressure_pa = load_n / area_m2

print(f"Load: {load_n:.1f} N")
print(f"Pressure: {pressure_pa:,.2f} Pa")
print(f"Safe: {pressure_pa < 5000}")

Expected output: Load: 1234.6 N, Pressure: 4,938.27 Pa, and Safe: True. .1f means one decimal place; ,.2f adds thousands separators and two decimal places.

Quotes and multiline text

message = "The sensor status is 'OK'."
report = """Test report
Material: Steel
Status: passed"""

print(message)
print(report)

Expected output: the first line contains the word 'OK'; the report prints on three lines. Different quote types help when text itself contains a quote.

Use f-strings for clear output: f"Temperature: {temperature_c:.1f} °C". They are usually easier to read than joining many strings with +.
Do not place untrusted user text directly into commands or file paths. For now, treat input as data and print it safely; validation comes later.
