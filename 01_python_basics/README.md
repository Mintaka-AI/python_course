# Module 1: Python Basics

Required foundation: syntax, variables, data types, casting, strings, operators,
input, conditions, loops, collections, functions, debugging, comprehensions,
imports, simple files and paths, and basic error handling. Module 2 provides
deeper practice with project structure, file formats, type hints, and pytest.

The optional post-foundation Advanced Python Track adds generators, decorators, object-oriented design,
dataclasses, advanced typing, context managers, logging, CLI programs,
concurrency, asyncio, and engineering AI-agent patterns.

## Structure

- `theory/` — HTML theory lessons
- `examples/` — code samples and practical exercises

## Start Here

- Open [`theory/index.html`](theory/index.html) to study the lessons in order.
- Run the programs in `examples/` from the MSYS2 UCRT64 terminal.
- Complete `examples/beam_check.py` after finishing the required foundation.
- Every linked source file must be run from the MSYS2 UCRT64 terminal, for example
  `python examples/10_strings_fstrings.py`; opening a file only shows its source.
- Study the optional Advanced Python Track only after completing the required foundation.
