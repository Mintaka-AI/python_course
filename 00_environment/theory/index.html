Module 0: Environment Setup

Technical reference: For deeper study, see the official Using Python 3.14 and venv documentation.

Before writing Python programs, we need a reliable workspace. In this course, we use Windows + MSYS2 UCRT64 only.

Course rule: run every terminal command from the MSYS2 UCRT64 terminal. Do not use PowerShell, Command Prompt, MSYS, or MINGW64 for this course.

Learning goals

By the end of this module, you will be able to:

  • open the MSYS2 UCRT64 terminal;
  • install Python and useful tools with pacman;
  • check which Python interpreter is running;
  • create and activate a project virtual environment;
  • run a first Python program.
  • choose appropriate optional numerical, statistical, plotting, and build tools for an engineering project.

1. Why use MSYS2 UCRT64?

Windows can have several Python installations. For example, Python may come from the Microsoft Store, a separate installer, or MSYS2. Mixing them causes common beginner problems: a package installs successfully but Python cannot import it.

MSYS2 is a development environment for Windows. Its UCRT64 terminal gives us one consistent set of tools: Python, pip, Git, and Unix-like commands such as pwd and ls.

Important: a package installed in one Python installation is not automatically available in another one. Always check the active Python with which python.

Why MSYS2 is useful for engineering work

Engineering projects often combine several tools: Python for automation, compiled libraries for fast calculations, Git for source control, plotting tools for graphs, and numerical or statistical software. MSYS2 provides these tools through one package manager and one UCRT64 environment.

  • Reproducibility: write the package names and installation commands in a project README so another engineer can create a similar environment.
  • Compatible toolchain: UCRT64 packages are built for the same Windows runtime, which reduces conflicts between compilers and libraries.
  • Automation: shell commands, Python scripts, Git, and build tools can be used together from one terminal.
  • Open-source tools: numerical, plotting, statistics, and compiler tools can be installed without using many unrelated installers.
MSYS2 does not replace commercial engineering software, engineering standards, or an engineer's judgement. It is a development environment for creating reproducible scripts and tools around calculations.

MSYS2 terminals: why UCRT64?

MSYS2 offers several terminals. This course fixes one choice: UCRT64. UCRT is the modern Universal C Runtime supplied by Windows. Keeping all tools in UCRT64 helps prevent an executable from one environment loading incompatible libraries from another one.

Finding and installing UCRT64 packages

pacman searches and installs packages. Search before installing optional tools, because package names and availability can change. 

pacman -Ss octave
pacman -Ss python-numpy
pacman -Ss gnuplot
pacman -Ss r$

A UCRT64 package name normally starts with mingw-w64-ucrt-x86_64-. Do not install a package with the mingw-w64-x86_64- prefix: that prefix belongs to MINGW64, not UCRT64.

GNU Octave: numerical computing

GNU Octave is a free numerical computing environment with a language similar to MATLAB. It is useful for matrix calculations, linear algebra, numerical methods, signal processing, control-system experiments, and plotting. 

pacman -S mingw-w64-ucrt-x86_64-octave
octave --version
octave

In the Octave prompt, try a small matrix calculation: 

A = [1, 2; 3, 4]
b = [5; 6]
x = A \ b

Octave is optional in this Python course. Use it when an existing team workflow uses MATLAB-like scripts; use Python as the main automation and AI-agent language in this course.

R: statistical computing and data analysis

R is a programming language and environment for statistics, data analysis, experimental design, and high-quality statistical graphics. It is especially useful for analysing laboratory results, reliability data, quality-control measurements, and regression models. 

pacman -S mingw-w64-ucrt-x86_64-r
R --version
R
measurements <- c(19.8, 20.1, 20.0, 20.3)
mean(measurements)
sd(measurements)

R is also optional. For this course, use Pandas and Matplotlib first. Learn R when it is required by your engineering team or data-analysis workflow.

3. Open the correct terminal

From the Windows Start menu, open MSYS2 UCRT64. Its prompt normally contains UCRT64. 

echo $MSYSTEM
which python
python --version

The first command should print UCRT64. The Python path normally contains /ucrt64/bin/python, unless a virtual environment is active.

4. Update MSYS2 packages

A package manager installs and updates software. In MSYS2, the package manager is called pacman. 

pacman -Syu

If the update asks you to close the terminal, close it, open MSYS2 UCRT64 again, and run pacman -Syu one more time.

5. Install Python, pip, virtualenv, and Git

Install the UCRT64 versions of the course tools. The long package names are normal: they make it clear that these packages belong to UCRT64. 

pacman -S mingw-w64-ucrt-x86_64-python mingw-w64-ucrt-x86_64-python-pip mingw-w64-ucrt-x86_64-python-virtualenv git

6. Check Python and pip

Run these commands after installation: 

python --version
python -m pip --version
which python

We use python -m pip, instead of only pip. It tells Python to run the pip that belongs to that same interpreter.

7. Projects and paths

A project is a folder containing related files. In the UCRT64 terminal, Windows drives are written differently:

  • Windows path: C:\Users\student\projects
  • UCRT64 path: /c/Users/student/projects

Useful navigation commands:

pwd
ls
cd /c/Users/student/projects
mkdir first_python_project
cd first_python_project

8. Virtual environments

A virtual environment is an isolated Python installation inside one project. It keeps the project’s packages separate from other projects. 

python -m venv .venv
source .venv/Scripts/activate
which python
python -m pip install --upgrade pip

After activation, the terminal prompt usually starts with (.venv). Also, which python should point to .venv/Scripts/python.

To leave the environment, run:

deactivate

9. Your first Python program

Create a file named hello.py and add this line: 

print("Python is ready for engineering!")

Run it from the folder containing the file:

python hello.py
