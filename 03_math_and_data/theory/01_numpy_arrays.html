NumPy Arrays and Vector Calculations

Learning goals

  • Create one- and two-dimensional arrays.
  • Calculate all measurements without a manual loop.
  • Select values, inspect shape, and understand numerical precision.

1. What is NumPy?

NumPy is a third-party numerical library. Its main object is ndarray: a fixed-shape collection of values, normally of one numeric data type. A one-dimensional array can represent repeated sensor readings; a two-dimensional array can represent a matrix or table of numbers.

import numpy as np
forces_n = np.array([10_000.0, 12_500.0, 15_000.0])
print(forces_n)
print(forces_n.shape)
print(forces_n.dtype)

np.array converts the Python list. shape reports three positions as (3,); dtype describes how the numbers are stored.

2. Vectorized calculation

areas_m2 = np.array([0.0008, 0.0008, 0.0010])
stresses_pa = forces_n / areas_m2
stresses_mpa = stresses_pa / 1_000_000
print(stresses_mpa)

Division happens position by position: first force by first area, second by second, and so on. The expected values are approximately [12.5, 15.625, 15.0] MPa. This operation is called vectorization.

3. Ranges, selection, and summaries

positions_m = np.linspace(0.0, 2.0, 5)
print(positions_m)
print(stresses_mpa[0])
print(stresses_mpa[stresses_mpa > 14.0])
print(stresses_mpa.mean())

linspace includes evenly spaced start and end values. Square brackets select one item or use a Boolean condition as a mask. mean() calculates the arithmetic average.

4. Matrices

coefficient_matrix = np.array([[2.0, 1.0], [1.0, 3.0]])
load_vector = np.array([5.0, 7.0])
solution = np.linalg.solve(coefficient_matrix, load_vector)
print(solution)

np.linalg.solve solves a linear system. A successful numeric answer still requires checking model meaning, conditioning, units, and residuals.

5. Floating-point limits

Most NumPy decimal calculations use binary floating-point. Some decimal fractions cannot be represented exactly. Use tolerances such as np.isclose for comparisons instead of assuming every computed decimal is exactly equal.

Arrays make repeated calculations fast, but they also repeat a unit or formula mistake quickly. Confirm matching shapes and units before calculating.

Common mistakes

  • Using Python lists and expecting element-by-element arithmetic.
  • Combining arrays with incompatible shapes.
  • Mixing N with kN or Pa with MPa.
  • Testing computed floats with exact equality.
