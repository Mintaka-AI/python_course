Module 3: Mathematics and Data Analysis

This module introduces numerical arrays, symbolic formulas, tabular data, and plots. Each library solves a different problem: NumPy calculates efficiently with many numbers, SymPy manipulates exact formulas, pandas works with labelled tables, and Matplotlib visualizes results.

Activate the project .venv in MSYS2 UCRT64, then install the optional libraries with python -m pip install numpy sympy pandas matplotlib openpyxl.

Lessons

  1. NumPy arrays and vector calculations
  2. SymPy formulas and equations
  3. pandas tables and measurements
  4. Matplotlib engineering plots

Module project

Load a measurement table, clean and calculate results, create a labelled graph, and save both the processed data and plot. State units, assumptions, and invalid-data decisions.
