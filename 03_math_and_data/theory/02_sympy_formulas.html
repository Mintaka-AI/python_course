SymPy Formulas and Equations

Learning goals

  • Create symbolic variables and expressions.
  • Substitute values and solve equations.
  • Differentiate and integrate a formula.

1. Numeric and symbolic calculation

Ordinary Python and NumPy calculate with chosen numeric values. SymPy can keep names such as force and area inside an exact mathematical expression. A symbol represents an unknown or variable quantity.

from sympy import symbols
force_n, area_m2 = symbols("force_n area_m2", positive=True)
stress_pa = force_n / area_m2
print(stress_pa)

The result remains force_n/area_m2. The assumption positive=True tells SymPy these symbols represent positive values, which can simplify later reasoning.

2. Substitute numeric values

numeric_stress = stress_pa.subs({force_n: 120_000, area_m2: 0.0008})
print(numeric_stress)
print(float(numeric_stress))

subs replaces symbols. SymPy preserves exact forms when possible; float() requests a floating-point approximation.

3. Solve an equation

from sympy import Eq, solve
stress_limit_pa = 150_000_000
equation = Eq(force_n / area_m2, stress_limit_pa)
required_area = solve(equation, area_m2)
print(required_area)

Eq represents equality rather than testing it. solve rearranges the equation for the requested symbol. Its result is a list because equations can have multiple solutions.

4. Derivatives and integrals

from sympy import diff, integrate
x = symbols("x", real=True)
deflection = 0.002 * x**2
slope = diff(deflection, x)
area_under_curve = integrate(deflection, (x, 0, 2))
print(slope)
print(area_under_curve)

diff differentiates with respect to x. integrate computes the definite integral from 0 to 2.

Symbolic algebra verifies transformations, not the physical model. Reject nonphysical roots and check assumptions, units, domains, and applicable standards.

Common mistakes

  • Using == when an algebraic equation needs Eq.
  • Assuming the first solution is physically valid.
  • Converting to float too early and losing exactness.
