Matplotlib Engineering Plots

Learning goals

  • Create a line plot with the object-oriented interface.
  • Label axes with quantities and units.
  • Compare series and save a reproducible figure.

1. Figure and axes

Matplotlib is a plotting library. A Figure is the complete image; an Axes is the plotting area containing lines, labels, ticks, and a legend.

import matplotlib.pyplot as plt
strain = [0.0, 0.0005, 0.0010, 0.0015]
stress_mpa = [0.0, 100.0, 200.0, 295.0]
fig, ax = plt.subplots()
ax.plot(strain, stress_mpa, marker="o", label="Specimen A")
ax.set_xlabel("Strain (m/m)")
ax.set_ylabel("Stress (MPa)")
ax.set_title("Stress–strain measurement")
ax.grid(True)
ax.legend()
plt.show()

plot pairs each x value with a y value. Markers show measured points; a connecting line helps show the trend. The axis labels state both quantity and unit.

2. Plot more than one series

ax.plot(strain, stress_mpa, marker="o", label="Measured")
elastic_model_mpa = [200_000 * value for value in strain]
ax.plot(strain, elastic_model_mpa, linestyle="--", label="Linear model")

A legend distinguishes measured and modelled data. Use style as well as color so the plot remains understandable in grayscale.

3. Save the figure

from pathlib import Path
output_path = Path(__file__).parent / "stress_strain.png"
fig.tight_layout()
fig.savefig(output_path, dpi=150)
print(f"Saved: {output_path}")

tight_layout reduces clipped labels. savefig writes a reproducible image; dpi controls raster resolution.

4. Choose an honest visual form

Use a line for an ordered continuous variable, scatter points when observations should not imply connection, and separate axes only when different scales truly require them. Do not truncate axes or smooth data in a way that hides important behavior without disclosure.

A graph can look convincing even when data, units, or scales are wrong. Verify source data and label every transformation.
