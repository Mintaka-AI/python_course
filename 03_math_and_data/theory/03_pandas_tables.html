pandas Tables and Measurement Data

Learning goals

  • Create and inspect a DataFrame.
  • Load CSV and Excel data.
  • Filter, clean, group, and summarize measurements.

1. Series and DataFrame

pandas is a third-party data-analysis library. A Series is a labelled one-dimensional sequence. A DataFrame is a two-dimensional table whose columns have names and whose rows have an index.

import pandas as pd
measurements = pd.DataFrame({
    "sensor_id": ["A", "A", "B"],
    "temperature_c": [20.1, 20.4, 19.9],
})
print(measurements)
print(measurements.dtypes)

The dictionary keys become column names. dtypes shows how pandas stores each column.

2. Load and inspect a file

from pathlib import Path
path = Path(__file__).parent / "sensor_measurements.csv"
data = pd.read_csv(path)
print(data.head())
print(data.info())

read_csv returns a DataFrame. head() previews rows. info() reports columns, missing values, and data types. For Excel, use pd.read_excel(path) with openpyxl installed.

3. Select, filter, and calculate

valid = data[data["temperature_c"].between(-50, 150)].copy()
valid["temperature_k"] = valid["temperature_c"] + 273.15
print(valid[["sensor_id", "temperature_k"]])

between creates a Boolean condition. Brackets filter matching rows. .copy() creates an independent table before adding a calculated column.

4. Missing data and summaries

print(data.isna().sum())
clean = data.dropna(subset=["temperature_c"])
summary = clean.groupby("sensor_id")["temperature_c"].agg(["count", "mean", "min", "max"])
print(summary)

isna identifies missing values. dropna removes rows only after an explicit decision. groupby calculates separate summaries for each sensor.

5. Outliers require a documented rule

An outlier is unusual relative to other values; it is not automatically an error. Flag suspicious values, retain the original data, and record the reason for exclusion or correction.

Never silently delete missing or unusual engineering measurements. Preserve the raw source and document every cleaning decision.
