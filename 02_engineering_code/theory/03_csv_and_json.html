CSV and JSON Data

Structured data has an agreed layout. CSV stores a table of comma-separated text values; JSON stores named values, lists, and nested objects. Engineering programs commonly read measurements as CSV and export calculated results as JSON.

1. Read a CSV table

import csv
from pathlib import Path
path = Path(__file__).parent / "measurements.csv"
with path.open(newline="", encoding="utf-8") as csv_file:
    for row in csv.DictReader(csv_file):
        load_kn = float(row["load_kn"])
        area_m2 = float(row["area_m2"])

DictReader reads the first row as headers. For the course CSV, row["load_kn"] selects a value by its column name. CSV values arrive as text, so convert numerical fields with float() before calculating.

2. Calculate each record

force_n = load_kn * 1_000
stress_pa = force_n / area_m2
stress_mpa = stress_pa / 1_000_000
print(f"Stress: {stress_mpa:.2f} MPa")

This converts kN to N first. It then converts Pa to MPa only for display. Keep conversions explicit so a reviewer can check them.

3. Export JSON

import json
result = {"test_id": 1, "stress_mpa": 15.62, "unit": "MPa"}
json_text = json.dumps(result, indent=2)
print(json_text)
same_result = json.loads(json_text)

dumps turns Python data into JSON text; loads turns JSON text back into Python data. The unit is included because a bare number is ambiguous.

4. Data quality checks

CSV does not prove that headers, units, or numbers are correct. A missing header raises KeyError; invalid numeric text raises ValueError. Later lessons validate and handle these clearly.
