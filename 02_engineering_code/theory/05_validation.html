Input Validation

Validation checks whether data satisfies the rules of a calculation before the calculation uses it. It is not the same as type hints: a value may be a float but still be physically impossible.

1. Validate at the function boundary

def calculate_stress_pa(force_n: float, area_m2: float) -> float:
    if force_n < 0:
        raise ValueError("Force must not be negative.")
    if area_m2 <= 0:
        raise ValueError("Area must be greater than zero.")
    return force_n / area_m2

The function refuses invalid values before division. A clear error message describes the correction needed. This protects every caller: a command-line program, a test, and a future agent tool.

2. Convert, then validate

def positive_float(text: str) -> float:
    value = float(text)
    if value <= 0:
        raise ValueError("Value must be greater than zero.")
    return value

float() may raise ValueError for non-numeric text. After conversion, apply the physical range rule.

3. Useful validation questions

  • Is every required field present?
  • Is the value a number?
  • Is it within the permitted physical range?
  • Is the unit known and compatible?
  • Are the model assumptions satisfied?
Passing validation does not make a result safe for real design. It only confirms the program’s stated rules.
