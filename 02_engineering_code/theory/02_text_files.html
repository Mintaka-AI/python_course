Text Files, Paths, and with

A program loses ordinary variables when it stops. A text file stores information for a later program run or for a person to read. A path is an address that identifies a file or folder.

1. Use Path for file addresses

from pathlib import Path
examples_dir = Path(__file__).parent
note_path = examples_dir / "module_1_note.txt"
print(note_path)

Path(__file__).parent means “the folder containing this program.” The slash joins path parts; it is not arithmetic division here. This is safer than assuming the current terminal folder.

2. Read a text file

with note_path.open("r", encoding="utf-8") as note_file:
    note_text = note_file.read()
print(note_text)

"r" is read mode. read() returns all text as one string. The with statement guarantees that Python closes the file after the indented block, including if an error happens.

3. Write a report

report_path = Path("stress_report.txt")
report_text = "Maximum stress: 150.0 MPa\nStatus: review required\n"
with report_path.open("w", encoding="utf-8") as report_file:
    report_file.write(report_text)

"w" creates a file or replaces existing contents. "a" appends to an existing file. \n begins a new line.

4. Choose the right operation

GoalModeRisk
Read an existing file"r"Missing file raises FileNotFoundError.
Create or replace a report"w"Existing contents are lost.
Add a log entry"a"Repeated runs add repeated lines.
Never write an important report until you understand its destination and overwrite behavior.
