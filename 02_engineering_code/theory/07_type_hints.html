Type Hints

Type hints document what values a function expects and returns. They improve editor suggestions and can be checked by optional tools. Python itself normally does not enforce them while running.

1. Read a signature

from pathlib import Path
def calculate_stress_pa(force_n: float, area_m2: float) -> float:
    return force_n / area_m2
def load_measurements(path: Path) -> list[dict[str, float]]:
    ...

force_n: float documents a decimal number. -> float documents the return value. The longer hint says “a list of dictionaries with text keys and float values.”

2. Hints are not validation

calculate_stress_pa("1200", "0.02")  # strings are not converted
calculate_stress_pa(1_200, 0)       # zero area is not rejected by a hint

Still convert input and validate physical rules. Hints describe the contract; validation enforces it.

3. Use hints where they help

Begin with function parameters and returns, especially reusable calculation functions. Prefer simple accurate hints over complicated annotations that obscure beginner code.
