Python Modules, Imports, and the Main Guard

As a program grows, one Python file becomes difficult to read and test. It may contain formulas, file handling, user messages, and program startup code all in one place. Modules let us divide that work into small files with clear jobs.

In this lesson: a module is simply a Python file. For example, calculations.py is a module. It can contain functions that another Python file imports and uses.

1. Why use modules?

Imagine an engineering program that reads a CSV file, checks measurements, calculates stress, prints a report, and runs tests. Keeping every line in main.py makes it hard to answer basic review questions: “Where is the formula?” and “Can I test the formula without opening a file?”

Instead, separate the responsibilities:

engineering_project/
├── calculations.py       # Calculation functions and validation rules
├── main.py               # Starts the application and displays results
├── data/
│   └── measurements.csv  # Input measurements
└── test_calculations.py  # Automated checks for calculation functions

This structure is not mandatory for every two-line script. It becomes useful as soon as a formula needs reuse, testing, or independent review.

2. Create a module

Create a file named calculations.py in the project folder. Put a calculation function in it:

# calculations.py

def rectangle_area_m2(length_m: float, width_m: float) -> float:
    """Return the area of a rectangle in square metres."""
    if length_m < 0 or width_m < 0:
        raise ValueError("Length and width must not be negative.")
    return length_m * width_m

The filename without .py is the module name: calculations. The function is available to another file only after that file imports it.

3. Import one function

Create main.py in the same folder as calculations.py:

# main.py

from calculations import rectangle_area_m2

length_m = 2.5
width_m = 1.2
area_m2 = rectangle_area_m2(length_m, width_m)

print(f"Area: {area_m2:.2f} m²")

Run python main.py. Python first finds calculations.py, then makes the requested function name available in main.py. The expected output is Area: 3.00 m².

Read the import line

from calculations import rectangle_area_m2
  • calculations is the filename calculations.py, without its extension.
  • rectangle_area_m2 is the name defined inside that file.
  • Do not write from calculations.py import ...; the .py extension is not used in an import statement.

4. Import the whole module

You can also import the module itself:

import calculations

area_m2 = calculations.rectangle_area_m2(2.5, 1.2)
print(f"Area: {area_m2:.2f} m²")

The dot means “use a name from this module.” This form makes the origin of the function very clear. Both forms are valid:

ImportCallUse it when
from calculations import rectangle_area_m2rectangle_area_m2(...)You use a small number of focused names.

Avoid from calculations import *. It imports many names without showing their origin, which makes engineering code harder to review.

5. What happens when Python imports a module?

Python runs the top-level statements in a module once when it imports it. Function definitions are safe at the top level: Python records the function, but does not run its body until the function is called.

# calculations.py
print("calculations module is being loaded")

def add_force_n(first_force_n: float, second_force_n: float) -> float:
    return first_force_n + second_force_n

When another file writes import calculations, the message prints immediately. The function body does not run until code calls calculations.add_force_n(...). This is why modules should normally define reusable items at the top level but should not automatically start a full program there.

6. The main guard: if __name__ == "__main__"

Every Python file has a special variable called __name__. Its value changes depending on how the file is used:

How the file is usedValue of __name__
You run python main.py"__main__"
Another file imports main"main"

A main guard is an if statement that runs startup code only when the file is executed directly:

def main() -> None:
    """Run the engineering calculator."""
    area_m2 = rectangle_area_m2(2.5, 1.2)
    print(f"Area: {area_m2:.2f} m²")


if __name__ == "__main__":
    main()

When you run this file directly, __name__ == "__main__" is true, so Python calls main(). When a test imports the file, the condition is false, so the program does not unexpectedly print output, read files, or ask for input.

Why use a function named main()?

main is only a normal function name, not a Python keyword. The convention helps readers find the program’s starting sequence. It also allows a test to call main() deliberately if needed.

7. A complete two-file example

Place these files in one folder and run python main.py.

# calculations.py
def calculate_stress_pa(force_n: float, area_m2: float) -> float:
    if force_n < 0:
        raise ValueError("Force must not be negative.")
    if area_m2 <= 0:
        raise ValueError("Area must be greater than zero.")
    return force_n / area_m2

# main.py
from calculations import calculate_stress_pa

def main() -> None:
    stress_pa = calculate_stress_pa(120_000, 0.0008)
    print(f"Stress: {stress_pa / 1_000_000:.2f} MPa")

if __name__ == "__main__":
    main()

The formula module can now be used by main.py, an automated test, or a future AI-agent tool without copying the formula.
