Testing Calculations with pytest

A test is code that checks an independently known expectation. Tests guard against accidental changes to formulas and make calculation functions safer to reuse.

1. Test a normal result

from calculations import rectangle_area_m2
def test_rectangle_area_m2() -> None:
    assert rectangle_area_m2(2.5, 1.2) == 3.0

assert means the condition must be true. pytest finds files and functions whose names start with test.

2. Test invalid input

import pytest
from calculations import calculate_stress_pa
def test_stress_requires_positive_area() -> None:
    with pytest.raises(ValueError):
        calculate_stress_pa(1_200, 0)

A correct program must reject impossible values as well as calculate normal ones. Include boundaries such as zero and negative values.

3. Run tests

cd 02_engineering_code/examples
python -m pytest

Run pytest through python -m so it uses the active project environment. A failure is information: read the expected and actual values, correct the code or expectation, then run again.

Passing tests prove only the examples you wrote. Test values, units, limits, and requirements must themselves be independently reviewed.

Try it yourself

Add a test for negative force. Change an expected value deliberately, observe the failure, then restore the correct test.
