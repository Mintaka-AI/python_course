Error Handling

An exception is Python’s way of reporting that an operation cannot continue normally. Expected failures—such as a missing input file or invalid number—need a clear response. Do not hide them or invent a replacement measurement.

1. Handle a missing file

from pathlib import Path
path = Path("measurements.csv")
try:
    text = path.read_text(encoding="utf-8")
except FileNotFoundError:
    print(f"Cannot find measurement file: {path}")
else:
    print(f"Loaded {len(text)} characters.")
finally:
    print("Load attempt finished.")

Put only the risky operation in try. The matching except handles one known problem. else runs after success; finally runs in both paths and is useful for cleanup.

2. Raise a meaningful error

def density_kg_m3(mass_kg: float, volume_m3: float) -> float:
    if volume_m3 <= 0:
        raise ValueError("Volume must be greater than zero.")
    return mass_kg / volume_m3

raise stops an invalid calculation at its source. The caller can catch the error and request corrected data.

3. Avoid hiding mistakes

Do not write a bare except:. It catches unexpected programming bugs too. Catch the particular error you expect and let unknown errors remain visible during development.
